SpendWise APK - GitHub se free mein banao (coding nahi chahiye)
1) github.com par free account > New repository (naam: spendwise).
2) "uploading an existing file" par click karo, is folder ki SAARI files drag-drop karo
   (.github folder ke saath; zip nahi, extract karke andar ki files) > Commit.
3) Repo mein "Actions" tab > "Build APK" > "Run workflow". 4-6 minute wait.
4) Run khatam hone par neeche Artifacts mein "SpendWise-APK" download karo > zip extract > app-debug.apk.
5) APK phone mein bhejo > open karo > "Install unknown apps" allow karo > Install.
Icon: assets/ folder mein hai (apna icon chahiye to icon-only.png badal do).
