SpendWise – Expense Tracker

A web and Android app to track daily expenses with charts and budget alerts.
B.Tech CSE Minor Project

## Features
- Add and delete expenses (title, amount, category, date)
- Live total, top category and budget left
- Category donut chart and 6-month bar chart
- Budget progress bar with colour alerts
- Works offline, data saved on device
- Installable Android app (APK)

## Tech Stack
HTML5, CSS3, JavaScript, SVG charts, localStorage, Capacitor (APK), GitHub Actions

## Download
Go to the **Actions** tab, open the latest run and download "SpendWise-APK".
